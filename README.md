# Azure Cost Visibility Dashboard

**Industry Relevance:**  
Designed for **finance, healthcare, insurance, and e-commerce**, this dashboard delivers real-time Azure spend visibility, AI-powered cost control, and automated resource optimization—addressing strict governance and transparency needs.

---

## Key Features

- Centralized Azure spend and per-service breakdowns
- AI-powered cost analysis & idle resource detection
- Budget forecasts, burn-down charts, and automated alerts
- Ready-to-use dashboards for finance, engineering, and cloud teams

## Business Value

Manual tracking and cost overruns threaten financial control—especially in regulated industries.  
**This dashboard enables proactive savings, fast audits, and compliance by centralizing cost analytics and automating budget alerts.**

---

## Tech Stack

- **Backend:** Node.js, Express, Azure APIs
- **Frontend:** React, Tailwind CSS, Recharts
- **AI:** Anthropic Claude-powered cost analysis
- **Auth:** Azure identity, HTTP Basic Auth

---

## Value Delivered

- Real-time, centralized Azure cost visibility
- Automated detection of spend anomalies and idle resources
- AI-driven recommendations for savings and compliance
